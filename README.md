## 🌟 Quick Start

To run the application locally:

```bash
# 1. Install dependencies (already completed)
npm install

# 2. Start the local development server
npm run dev
```

Open your browser at `http://localhost:3000` (or the port Vite prints in your console).

## 🍲 Key Features

1. **Interactive Bengaluru Live City Grid**: Real-time spatial map featuring major zones (Palace Grounds, Manyata Tech Park, Bellandur ORR, Whitefield, Peenya, HSR) with live traffic bottleneck indicators (Silk Board, Hebbal).
2. **Surplus Incident Intake & Demo Presets**: One-click demo triggers for:
   - 🏛️ *Palace Grounds Wedding Banquet* (130 hot meals)
   - 🏢 *Manyata Tech Park Corporate Cafeteria* (85 meals)
   - ⚠️ *Malleshwaram Danger Zone Test* (Triggers FSSAI microbial warning for room-temp coconut chutney)
3. **Agentic Orchestration Console**: Inspect the 4 collaborating autonomous agents:
   - **Agent 1: Food Quality & Safety Inspector** (FSSAI Rule Engine)
   - **Agent 2: Spatial & Corridor-Aware Logistics Matcher** (Bengaluru Traffic AI)
   - **Agent 3: Multilingual Dispatcher** (Kannada, Hindi, English)
   - **Agent 4: Human-in-the-Loop & Privacy Gate** (Zero Spoilage Guarantee)
4. **Human Review Gate (Mandatory Safety Requirement)**: Food Safety Officer verification queue with PII masking.
5. **Volunteer Mobile Hub**: PWA-ready mobile card with native Kannada (`ಆಹಾರ ಸಾಗಾಣಿಕೆ ನಿಯೋಜನೆ`), English, and Hindi dispatch text, route guidance, and dual verification security pins.
6. **Built with IBM Bob Interactive Showcase**: Dedicated walkthrough of how IBM Bob was leveraged across ideation, FSSAI regulatory modeling, spatial routing heuristics, and code synthesis.
7. **Measurable Impact Dashboard**: Live metrics tracking the **400+ kg daily redirect outcome**, meals served, and CO2 emissions prevented.
